# SQL Database Design and Implementation

## Overview

This project demonstrates practical experience in designing, building, and managing a relational database using SQL.

The project covers the full database development process, from planning the structure of the database and organising information efficiently, through to creating tables, managing data, writing queries, and producing reports and visualisations using Microsoft Excel.

The aim was to create a structured database that could be used to support a real-world business system.

## Database Design

The project includes an **Enhanced Entity-Relationship Diagram (EERD)** to plan the structure of the database before implementation.

The design shows:

- Main entities within the system
- Relationships between entities
- Primary and foreign keys
- How different types of information are connected
- The overall structure of the database

The database was designed with **normalisation** in mind to reduce unnecessary duplication and maintain data consistency.
